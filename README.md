## ⚡ Quick Installation

<div align="center">

**Install any theme with a single command!**

</div>

```bash
# 🎨 Install Catppuccin Mocha (Example)
hydectl theme import --name "Catppuccin Mocha" --url "https://github.com/HyDE-Project/hyde-themes/tree/Catppuccin-Mocha"

# 🔄 Switch between installed themes
hydectl theme set "Theme Name"

# 📦 List all available themes
hydectl theme list
```

**🎥 See it in action:**

## 🛠️ Creating Custom Themes

<div align="center">

**Ready to create your own masterpiece?**

</div>

> [!TIP]  
> 🎨 **Want to create your own theme?** Check out our comprehensive [**Theming Wiki**](https://github.com/hyde-project/hyde/wiki/Theming)!
> 
> 🔧 **Theme Management Made Easy:** Use our powerful [**Theme Patcher**](https://github.com/hyde-project/hyde/wiki/Theming#theme-patcher) to install, browse, create, maintain, and share themes with the community!

### 🚀 Quick Start Guide

1. **Fork this repository**
2. **Create a new branch** with your theme name
3. **Follow the theming guidelines** in our wiki
4. **Submit a pull request** to share with the community
5. **Get featured** in our gallery!
